# UPGen: The Unidentified Protocol Generator

UPGen is a protocol generator for creating randomized Protocol Specification
Files (PSFs) for censorship circumvention. The PSFs generated by UPGen can be
used with [Proteus](https://github.com/unblockable/proteus). UPGen is able to
generate a vast number of distinct protocols: the analysis in our
[USENIX Security publication](https://www.usenix.org/conference/usenixsecurity25/presentation/wails)
shows on the order of $10^{22}$ distinct protocols are possible.

UPGen is designed to work when censors use a "blocklist strategy"; that is, when
censors maintain a set of rules to block particular protocols. The basic
security argument is that it would be difficult to block many or all UPGen
protocols without inadvertently blocking many other protocols (that are not
designed for circumvention).

## Quickstart

Install [uv](https://docs.astral.sh/uv/getting-started/installation/) and GNU
Make, then install UPGen and its dependencies:

```console
$ make sync
$ make download-model
$ make generate
```

`make download-model` downloads an example, pretrained greeting string model
from GitHub and extracts it into `build/`. If you wish to train your own model
instead, see the [greeting string model guide](docs/greeting_model.md) for
details.

Run `make` to list the available commands. Paths and generation options can be
overridden when needed, for example:

```console
$ make generate CONFIG_FILE=assets/config.json \
    NUM_GENERATED=5 PSF_FILE=build/examples.psf
```
