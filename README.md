# UPGen: The Unidentified Protocol Generator

UPGen is a protocol generator for creating novel Protocol Specification Files (PSFs) for encrypted communication.
It is written in Python and the PSFs generated by UPGen can be used in Proteus and other related tools.
The protocols generated by UPGen are astronomically large and around $4.1 \times 10^{25}$.
UPGen creates protocols that are unique and can not be easily identified as UPGen protocols.
This may cause difficulties to the censors which is unable to find it and tries to block all the unidentified protocols.
