# Documentation

To generate a PSF:

1. Follow the [installation guide](install.md).
2. Obtain the required greeting string model files. Downloading the example,
   pre-trained model is the quickest way to get started, but you can also train
   your own. See the [greeting string model guide](greeting_model.md).
3. Follow the [PSF generation guide](generate_psf.md).

Additional references:

- [Optional model training](train_model.md)
- [Command-line reference](cli.md)

The recipes in the Makefile can be used to download data, train greeting string
models, and generated PSFs.
